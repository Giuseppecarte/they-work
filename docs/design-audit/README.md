# Design audit

The working folder for the second audit of `they-work`. `GOAL.md` is the brief;
everything the audit produces belongs here beside it.

| File | |
| --- | --- |
| `GOAL.md` | the brief: appearance, design fidelity, ease of use, and the blind spots to attack |
| `FINDINGS.md` | what is wrong, ordered by consequence to a user |
| `CHANGES.md` | what was changed on the branch, and what was deliberately not |

Work happens on the branch `audit/design-and-usability`, never on `main`.

The first audit, which covered correctness rather than appearance, is at
[`../audit-2026-09-04.md`](../audit-2026-09-04.md). Its reproduction harness is
worth reusing.
