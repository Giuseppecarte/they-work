EVERY OFFICE ITS OWN
a project's look is derived from its name, so it is stable and needs no setup — and can be overridden

warm floor, violet walls
MIDNIGHT

ORCHARD
sage and olive
ARCADE
neon, high contrast
AUTOMATIC, AND STABLE
A theme is picked by hashing the office path, so the same project always looks the same on every machine and nobody has to configure anything to get a distinct-looking office.
they-work  →  SANDSTONE
gamma-research  →  MIDNIGHT
beta-platform  →  ORCHARD
they-work  →  ARCADE
OVERRIDABLE, NEVER REQUIRED
One optional file, read-only like everything else. Absent, the derived theme stands. It cannot break the office: unknown keys are ignored.
# they-work.toml, in the repo root
theme = "arcade"
title  = "THEY WORK"
sign  = "ship it"
WHAT A THEME CONTROLS
• floor plate and its grid lines
• wall colour and window glass
• desk and chair timber
• plant and set-dressing palette
• the sign above reception
It never controls the workers. Shirt colour always means agent, and status colour always means status — those must read identically in every office.
