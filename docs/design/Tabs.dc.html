THE RULE THAT CANNOT BEND
A floor draws exactly one office’s workers. Never a union, never a filter over everyone. If a thread changes directory it moves — it leaves the old desk before it takes the new one, so it can never be seen twice.
EACH FEED IS ITS OWN ROOM
The guard office is four separate rooms behind four separate panes, each with its own theme, sign and staff. It is not one big office with everyone in it — the frames are the point.
THE TAB KNOWS BEFORE YOU DO
A tab’s dot turns amber the moment anyone in that project blocks, even while you are looking somewhere else. That is the one thing worth pulling your eyes across the screen.
