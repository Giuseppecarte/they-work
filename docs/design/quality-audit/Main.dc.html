THE SIGN IS NOT WORDS
It reads THEY-HOAI! where it should read THEY-WORK. W draws as H, R as A, K as an exclamation. The letterform table is correct, so the glyph renderer is dropping the diagonals.
THE WORST RUNG SHIPS
Measured through a pty against the published tag: 9,975 half-blocks, 0 quadrants, 0 sextants. The runtime image sets no locale, so the renderer refuses anything better.
EVERY EDGE IS RAGGED
Half-blocks give one pixel across and two down, so the plate edge steps, walls fray, and loose pixels float free of their sprites. Horizontal detail costs twice what vertical does.
THE GOOD NEWS
None of this is the design being unachievable, and none of it is the user's terminal. The same code already draws the same scene at 1280 × 608 when a graphics protocol is negotiated — sixty-six times the pixels of what ships. The gap is packaging and a glyph bug, not art.
