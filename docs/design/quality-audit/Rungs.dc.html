WHERE EACH RUNG ACTUALLY LANDS
Windows Terminal 1.22+ under WSL reaches the graphics rung through Sixel. Kitty, WezTerm and Ghostty reach it through the Kitty protocol, on any platform. iTerm2 would through inline images, which is written but absent from the release. macOS Terminal and the VS Code terminal stay on characters — which is why the character rungs still have to be good.
